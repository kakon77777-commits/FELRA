# FELRA Data & Statistics Pipeline v0.4

## 證據鏈

$$
\text{原始 CSV}
\rightarrow
\text{欄位契約與品質檢查}
\rightarrow
\text{正規化資料快照}
\rightarrow
\text{資料列命題}
\rightarrow
\text{描述／推論統計}
\rightarrow
\text{圖形與機器可讀證據包}.
$$

FELRA 不覆寫來源資料。正規化資料只是按照專案規格產生的可重現投影，並以來源 SHA-256 連回原始檔案。

## 資料品質維度

每個資料集至少記錄：

- 讀取列數與保留列數；
- 被丟棄列數；
- 各欄缺失值與無效值；
- 宣告欄位上的重複列；
- 來源檔 SHA-256；
- 字元編碼、分隔符與錯誤策略。

## 統計邊界

統計檢定只在其假設、樣本設計與資料品質足夠時具有相應解釋力。v0.4 會計算統計量，但不會自動宣稱常態性、獨立性、隨機抽樣或因果識別已成立。

Bootstrap 分布依賴重抽樣次數與偽隨機種子；證據包必須保存兩者。重複批次則用不同種子檢查結果對有限計算擾動的穩定性。
